# Examples

Worked examples built on the documented capabilities. They are not part of
the package, nothing outside this folder refers to them, and each one says
which capabilities it uses and what it cannot tell. A test keeps them running
on the synthetic chains of the test suite, and another keeps the rest of the
repository from depending on them.

| example | what it shows |
|---|---|
| [`address-set-profile/`](address-set-profile/README.md) | aggregate profile of a list of addresses: history, co-spends, key exposure |
